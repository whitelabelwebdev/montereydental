# Monterey Dental Centre, homepage redesign

Static homepage concept for montereydental.ca (NE Calgary). All copy, photos, logos and the hero video come from the live site.

- `index.html`: the homepage
- `assets/css/style.css`, `assets/js/main.js`
- `assets/images/`: images and video from montereydental.ca
- `assets/fonts/`: Montserrat and Fraunces (self-hosted)

Menu items are placeholders until the inner pages are built.
